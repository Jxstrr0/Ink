# src/: the source of index.html

**Edit `src/`, run `node build.js`, commit both `src/` and `index.html` (and `sw.js`). Never hand-edit `index.html`.**

`index.html` is the shipped artifact: one self-contained page, served by GitHub Pages from `main` and saved for offline use. `build.js` (repo root, node, no dependencies, lifted from Prairie Engine Works) concatenates the files listed in `src/manifest.txt`, in that order, byte for byte. It adds no wrappers and does no reformatting.

```
node build.js            # write index.html and sw.js from src/
node build.js --check    # exit 1 if index.html or sw.js != what src/ builds; names the first differing src file and line
```

## How the files fit together

- The files are **slices of one page**. A `.js` file may open or close in the middle of an IIFE, so `node --check` on a single file is meaningless. Test the built `index.html` instead.
- Every file except the last ends with a newline, and no file may be empty. `html/tail.html` holds the page's last line, with no trailing newline.
- A new file must be added to `manifest.txt` at the right position. `build.js` refuses to build if any file in `src/` (other than `.md`) is missing from the manifest, and also on leftover merge-conflict markers.
- The build also refuses a script block that does not compile, or that declares the same column-0 `function` twice.

### Script blocks

| block | first file (opens) | last file (closes) | what it is |
|---|---|---|---|
| **INK_SIM** | `sim/rng.js` (`<script>`, `const INK_SIM=(function(){`, `const SIM={}`) | `sim/market.js` (`return SIM;})();`, `module.exports` for node, `</script>`) | the simulation; every sim file adds to `SIM`. Runs in node: `tools/sim-test.js` cuts out `src/sim/*.js` in manifest order |
| **INK_SOUND** | `sound/synth.js` | `sound/synth.js` | the Web Audio synth |
| **INK_VIS** | `vis/core.js` (`<script>`, `(function(){`, the shared `V` state) | `vis/api.js` (`window.INK_VIS={…}`, `})();`, `</script>`) | three.js |
| **app** | `app/state.js` (`<script>`) | `app/help.js` (`</script>`) | one top-level script; scope is shared across the app files |

`html/tail.html` then runs `__ldGo(start)` (`start()` is in `app/boot.js`) and closes the page.

## PWA files (repo root, not in src/)

`manifest.webmanifest` and `icons/` are committed by hand (icons come from `node tools/make-icons.js`, needs Playwright). **`sw.js` is generated by `node build.js`**: its cache name is `ink-shell-v<VERSION>-<hash of index.html + manifest + icons>`, so every release changes it and installed copies show the update bar. `--check` fails if it is stale. The worker also precaches every CDN `<script src>` in the page plus the `INK_LIBS` array in `html/body.html`. Cache names all start with `ink-` because Prairie Engine Works shares the origin.

## VERSION

One place: `src/app/state.js`, `const VERSION="x.y.z.w";` (major.minor.feature.hotfix).

## The state object `S`

Defined once, in `freshState()` in `app/state.js`. Saved whole as `ink-save`. `hydrate()` lays a save over a fresh state, so a field added later gets its default in old saves.

| field | type | what it is |
|---|---|---|
| `v` | number | save format version (`SAVE_V`) |
| `week` | number | 1..52 within the year |
| `year` | number | 2000..2030 |
| `cash` | number | money on hand |
| `rate` | number | your hourly rate (PR 7: `RATE_BY_REP` × `PRICE_INDEX`); 0 while an apprentice |
| `rep` | object | the three reputation tracks `{walkins, collectors, peers}` (`REP_TRACKS`, PR 5) |
| `skills` | object | `{styles:{styleId:0..10}, consult, linework, shading, colour, speed}` (`SKILLS`, PR 7) |
| `kit` | object | machine, needles, inks, voltage (PR 4) |
| `clients` | array | client records (PR 3; shape in `docs/SIM-CONTRACT.md`), compacted past `CLIENT_CAP` (PR 7) |
| `pieces` | array | every tattoo: design parameters + session outputs + date, never pictures (PR 4, PR 5) |
| `queue` | array | booked sessions, including later sessions of multi-session pieces (PR 3, PR 4) |
| `studio` | object | `{stage: "apprentice"\|"chair"\|"studio"\|"legacy", staff:[]}` (PR 7) |
| `goals` | object | `GOALS` done, id → `{w, y}` (PR 8) |
| `board` | object | the design board (PR 2): `design` (the working design, shape in `docs/SIM-CONTRACT.md`, null = empty), `bodyShape` (`BODY_SHAPES` id), `skinTone` 0..1, `client` (a `DZ_SAMPLE_CLIENTS` id, or a real client id from PR 3), `item` (PR 3: the `S.queue` session item being designed for, or null) |
| `flash` | array | your own flash, saved from the board: `{id, name, design, w, y}`, at most `FLASH_MINE_CAP` (40) (PR 2) |
| `seed` | number | the career's rng seed (`INK_SIM.rng`) |
| `settings` | object | `theme` (dark/light/auto), `gfx` (null = auto, lite/full/ultra), `gfxAuto`, `sound`, `reduced` |
| `bkAt` | number | when the last backup was made (ms), 0 = never |

The sim's data shapes (designs, clients, elements, placements) are in `docs/SIM-CONTRACT.md`.
